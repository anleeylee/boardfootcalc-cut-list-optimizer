Cut List → Lumber Purchase Optimizer

Turn a woodworking cut list into an optimized, lowest-waste lumber purchase plan. The tool matches every required part against your existing inventory and supplier stock, places pieces along boards with kerf accounted for, and explains every board, every placement and every unfulfilled part in plain text.

TypeScriptNode.js ≥ 18MIT License20 tests

Part of the open-source BoardFootCalc desktop tool suite — the same board-foot math as the online lumber calculators, offline and scriptable on your own machine.

Features

  • 1D cutting-stock optimization over whole boards: 4 strategies (lowest-cost, lowest-waste, min-boards, balanced).
  • Existing inventory reuse — AVAILABLE boards are preferred and valued at their on-hand cost; supplier boards are priced at cost/BF + fixed cost.
  • Kerf-aware — a saw kerf is consumed between every pair of pieces, never ignored.
  • Compatibility filtering — species, thickness quarter (8/4 vs 4/4), width (with rotation when grain allows), grain direction and edge requirements.
  • Defect zones — subtract defect areas from usable board length.
  • Explainable — every board plan lists each piece, its start position, and why unfulfilled parts could not fit.
  • Exports — purchase list CSV, cutting plan JSON, project file (.lumberproject).

Quick start

npm run demo
bfc-optimize run --project myjob.lumberproject --strategy balanced --kerf 0.125 --waste 0.3

Full CLI reference, input formats and design notes are in the repository README.
